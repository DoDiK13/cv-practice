# Библиотека и консольный скрипт фильтров изображений

Python-библиотека и консольная утилита для обработки изображений с использованием библиотек **NumPy** и **OpenCV**. Проект содержит набор из 8 фильтров с настраиваемыми параметрами, позволяющих изменять размеры изображений, преобразовывать цвета, добавлять эффекты плёнки, шума, свечения и другие визуальные эффекты.

## Инструкция по использованию

Для работы библиотеки требуется Python 3.8+. Основные вычисления и операции над изображениями выполняются с помощью библиотеки NumPy. Для чтения и сохранения изображений используется OpenCV.

### Установка зависимостей

Установите необходимые пакеты с помощью pip:

```bash
pip install numpy opencv-python
```

**Примечание:** NumPy используется для выполнения математических операций над матрицами изображений. OpenCV используется исключительно для чтения и сохранения изображений, а также преобразования цветовых пространств.

## Инструкция по запуску

Скрипт запускается через командную строку:

```bash
python ImageProcessing.py --input <путь_к_входному_файлу> --output <путь_к_выходному_файлу> --filter <название_фильтра> [--params параметр=значение ...]
```

Также доступны сокращённые варианты аргументов:

- `-i` — путь к входному изображению;
- `-o` — путь для сохранения обработанного изображения;
- `-f` — название фильтра;
- `-p` — параметры выбранного фильтра.

Поддерживаются следующие названия фильтров:

- `resize` — изменение размера;
- `grayscale` — перевод в оттенки серого;
- `antique` — эффект старины;
- `fadecolor` — эффект выцветания;
- `tape` — имитация плёнки;
- `matte` — наложение овальной маски;
- `noize` — добавление шума и царапин;
- `neon` — эффект неонового свечения.

Параметры фильтров передаются в формате `key=value`. Числовые значения автоматически преобразуются в целые или вещественные числа.

Пример запуска:

```bash
python ImageProcessing.py -i test_image.png -o result.png -f antique --params intensivity=0.8 scale=100
```

Входной файл должен существовать, а папка для сохранения результата должна быть создана заранее.

При возникновении ошибок чтения, обработки или сохранения изображения программа выводит сообщение об ошибке в стандартный поток ошибок и завершает выполнение с кодом 1.

## Структура проекта

Проект содержит следующие файлы:

- `cli_argument_parser.py` — модуль разбора аргументов командной строки, проверки путей и преобразования параметров фильтров;
- `image_io.py` — модуль чтения и сохранения изображений с помощью OpenCV, а также преобразования цветовых пространств;
- `filters.py` — модуль с абстрактным классом фильтра и реализацией всех восьми фильтров;
- `ImageProcessing.py` — главный файл проекта, содержащий функцию `main`, которая организует последовательность чтения, обработки и сохранения изображения.

## Описание математических алгоритмов и фильтров

### Алгоритм чтения изображения и преобразования цветового пространства

**Использование:**

Чтение изображения осуществляется функцией `read_image(path_to_image)` из модуля `image_io.py`.

**Алгоритм:**

1. Изображение считывается с помощью функции `cv2.imread()` в цветовом пространстве BGR.
2. Проверяется успешность чтения изображения. Если изображение не удалось загрузить, генерируется исключение `ValueError`.
3. С помощью функции `cv2.cvtColor()` изображение преобразуется из BGR в RGB.
4. Полученная матрица возвращается в формате NumPy.

Таким образом, все фильтры работают с изображениями в цветовом пространстве RGB.

### Алгоритм сохранения изображения

Сохранение осуществляется функцией `write_image(path_to_image, image)`.

**Алгоритм:**

1. Проверяется существование файла по указанному пути.
2. Если файл уже существует, он удаляется.
3. Изображение преобразуется из RGB обратно в BGR.
4. С помощью `cv2.imwrite()` выполняется сохранение результата.
5. Проверяется успешность записи файла. В случае ошибки генерируется исключение `ValueError`.

### Абстрактный класс ImageFilter

В модуле `filters.py` реализован абстрактный класс `ImageFilter`, определяющий общий интерфейс для всех фильтров.

Основной метод:

`apply_filter(image: np.ndarray) -> np.ndarray`

Принимает исходное изображение в виде массива NumPy и возвращает обработанное изображение.

Статический метод `get_filter(filter_type, **kwargs)` позволяет создать экземпляр необходимого фильтра по его названию и переданным параметрам.

### Алгоритм изменения размера Resize

**Использование:**

```bash
python ImageProcessing.py -i test_image.png -o test_resize.png -f resize --params width=1020 height=768
```

Принимает два обязательных параметра:

- `width` — ширина результирующего изображения;
- `height` — высота результирующего изображения.

**Алгоритм:**

Используется метод интерполяции ближайшего соседа (Nearest Neighbor).

1. Получаются исходные размеры изображения.
2. Вычисляются коэффициенты масштабирования по горизонтали и вертикали.
3. Для каждого пикселя результирующего изображения определяется соответствующая координата исходного изображения.
4. Координаты преобразуются к целочисленному типу, после чего выбираются ближайшие пиксели исходного изображения.
5. С помощью индексирования NumPy формируется результирующая матрица.

Алгоритм позволяет изменять разрешение изображения без выполнения дополнительных циклов по отдельным пикселям.

### Алгоритм перевода изображения в оттенки серого Grayscale

**Использование:**

```bash
python ImageProcessing.py -i test_image.png -o test_grayscale.png -f grayscale
```

Не принимает параметров.

**Алгоритм:**

В соответствии с телевизионным стандартом ITU-R Rec. 709 каждый пиксель изображения преобразуется в значение интенсивности по формуле:

`Intensity = 0.2126R + 0.7152G + 0.0722B`

Где:
- R — красный канал;
- G — зелёный канал;
- B — синий канал.

Вычисления выполняются векторизованно с использованием операций NumPy.

Если на вход поступает уже одноканальное изображение, функция возвращает его копию без дополнительных преобразований.

Результат преобразуется к типу `uint8`.

### Фильтр «Антиквариат» (Antique)

**Использование:**

```bash
python ImageProcessing.py -i test_image.png -o test_antique.png -f antique --params intensivity=0.7 scale=100
```

Принимает два опциональных параметра:

- `intensivity` — интенсивность применения эффекта сепии, по умолчанию 0.7. Диапазон от 0 до 1;
- `scale` — параметр, определяющий характеристики плёночного зерна, по умолчанию 10. Допустимый диапазон от 10 до 1000.

**Алгоритм:**

1. Если исходное изображение одноканальное, оно преобразуется в трёхканальное путём копирования интенсивности в каждый цветовой канал.
2. К каждому пикселю применяется матрица преобразования сепии.
3. Новые значения цветовых каналов вычисляются посредством умножения цветового вектора пикселя на транспонированную матрицу сепии.
4. Полученное изображение смешивается с исходным с использованием параметра `intensivity`:

Result = Image(1-intensivity)+Sepia\cdot intensivity

5. Результат ограничивается диапазоном от 0 до 255.
6. Для имитации старой фотографии добавляется пуассоновское плёночное зерно.

Для генерации зерна исходные значения нормализуются в диапазон от 0 до 1. Затем используется распределение Пуассона/

Полученное зерно вычитается из нормализованного изображения с коэффициентом 0.3.

### Фильтр выцветания (FadeColor)

**Использование:**

```bash
python ImageProcessing.py -i test_image.png -o test_fadecolor.png -f fadecolor --params max_fade=50
```

Принимает один опциональный параметр:

- `max_fade` — величина сжатия цветового диапазона, по умолчанию 50.0.

**Алгоритм:**

Фильтр уменьшает динамический диапазон интенсивности цветовых каналов, создавая эффект выцветшей фотографии.

1. Исходное изображение преобразуется к типу `float32`.
2. Определяются минимальное и максимальное значения результирующего диапазона.
3. Вычисляется коэффициент масштабирования.
4. Для каждого элемента изображения применяется формула:

Result = f_min + result * scale

5. Значения ограничиваются диапазоном от 0 до 255 и преобразуются к типу `uint8`.

В результате тёмные участки становятся светлее, а яркие — менее насыщенными по интенсивности, что создаёт эффект выцветания.

### Имитация плёнки (Tape)

**Использование:**

```bash
python ImageProcessing.py -i test_image.png -o test_tape.png -f tape --params mode=infrared grain_amount=0.3
```

Принимает два опциональных параметра:

- `mode` — тип плёнки, по умолчанию `infrared`. Поддерживаются значения `infrared` и `classic`;
- `grain_amount` — интенсивность плёночного зерна, по умолчанию 0.3. Диапазон от 0 до 1.

**Алгоритм:**

Применяет матрицы инфракрасной или винтажной пленки к цветам пикселей. Ниже приведены вычисления для инфракрасного фильтра:

`R' = 0.1*R + 1.5*B, -0.2*G`\
`G' = 0.6*R + 0.2*B, 0.1*G`\
`B' = -0.1*R + 0.1*B + 0.8*G`

Красный цвет чувствителен к зелёному, поскольку листва излучает инфракрасный свет и краснеет. Синий цвет (вода и небо) уводится в темные тона, так как поглощает инфракрасный свет. Зелёный канал приглушается.\
После вычсления цветов при помощи нормального распределения генерируется пленочное зерно, которое может сделать пиксель темнее или светлее. Оно применяется совместно с параболическим фильтром, делающим зернистый эффект виднее в полутонах (при интенсивности 0.5) и почти незаметным на ярких/темных участках.

### Состаривание фотографии (Noize)

**Использование:**

```bash
python ImageProcessing.py -i test_image.png -o test_noize.png -f noize --params noise_amount=0.008 num_scratches=12 scratch_intensity=0.7
```

Принимает три опциональных параметра:

- `noise_amount` — количество случайных шумовых точек, по умолчанию 0.004. Диапазон от 0 до 0.1;
- `num_scratches` — количество царапин, по умолчанию 12. Допустимы значения от 0 и выше;
- `scratch_intensity` — интенсивность белых царапин, по умолчанию 0.7. Диапазон от 0 до 1.

**Алгоритм:**

Фильтр имитирует физическое старение фотоплёнки посредством добавления светлых и тёмных шумовых точек, а также царапин.

1. Создаются две маски размером с исходное изображение: белая и чёрная.
2. Генерируется случайная матрица равномерно распределённых значений:
3. В соответствии с параметром `noise_amount` формируются светлые и тёмные шумовые точки. На белые точки приходится 60% вероятности возникновения шума, на чёрные — оставшиеся 40%.
4. Для генерации царапин создаются случайные начальные и конечные координаты.
5. С вероятностью 0.8 генерируются преимущественно вертикальные царапины, имитирующие движение плёнки через прокатный механизм.
6. Для построения линий используется интерполяция координат между начальной и конечной точками. К координатам добавляется небольшое случайное отклонение.

### Неоновое свечение (Neon)

**Использование:**

```bash

```

Принимает четыре опциональных параметра:

- `thickness` — толщина выделяемых границ, по умолчанию 2.0. Диапазон от 1 до 5;

3. Для выделения границ используется оператор Собеля.

## Обработка ошибок

В главном файле `ImageProcessing.py` предусмотрена обработка исключений на трёх этапах работы программы:

1. Чтение входного изображения и разбор аргументов.
2. Создание экземпляра фильтра и обработка изображения.
3. Сохранение результирующего изображения.

При возникновении ошибки программа выводит соответствующее сообщение в стандартный поток ошибок и завершает выполнение с кодом 1.

Это позволяет корректно обрабатывать ситуации, связанные с отсутствием входного файла, некорректными параметрами фильтра, ошибками обработки и невозможностью сохранения результата.
